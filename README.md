# 在线简历生成器

一个纯前端实现的在线简历制作网站：用户填写表单 → 实时生成排版好的 A4 简历 → AI 智能美化经历描述 → 一键导出 PDF。

## 功能特性

- **表单录入**：基本信息、教育背景、实习/工作经历、项目经历（支持多条动态添加/删除）、技能特长、自我评价
- **AI 智能美化**：填写工作内容、项目描述、个人简介、技能特长、自我评价时，点击「AI 美化」即可调用大模型润色——动词开头、量化成果、贴合招聘方阅读习惯；用户自行填写 API Key，支持 DeepSeek / 通义千问 / 智谱 GLM / Kimi / OpenAI 及任意 OpenAI 兼容接口
- **实时预览**：输入即更新，A4 纸张实时渲染，空白栏目自动隐藏
- **三套简历模板**：蓝色经典 / 深色头部 / 侧边栏双栏，一键切换，切换后自动记住
- **照片上传**：自动压缩到 320px 存本地，三套模板均支持显示，可随时移除
- **导出 PDF**：调用浏览器打印，输出干净的 A4 简历（占位符自动隐藏）
- **本地保存**：所有数据存于 localStorage，刷新、关闭浏览器都不丢失

## 快速开始

### 方式一：直接使用

下载本仓库后，双击 `index.html` 即可在浏览器中使用，无需安装任何环境。

### 方式二：在线使用（GitHub Pages）

1. 将本仓库推送到 GitHub
2. 仓库 Settings → Pages → Source 选择 `main` 分支 + `/ (root)` → Save
3. 约 1 分钟后访问 `https://你的用户名.github.io/仓库名/`

## 使用 AI 智能美化

1. 点击顶部工具栏的「**AI 设置**」按钮
2. 选择服务商（内置 DeepSeek、通义千问、智谱 GLM、Kimi、OpenAI 预设，也可选自定义填写任意 OpenAI 兼容接口地址），系统会自动填入默认的接口地址与模型名称
3. 填入**你自己的 API Key** 并保存（Key 仅保存在你自己浏览器的 localStorage 中，不会上传到任何服务器）
4. 在工作内容、项目描述、个人简介、技能特长、自我评价等文本框旁点击「**AI 美化**」，稍候片刻即可自动回填润色结果

> 说明：纯前端直连需要该服务商允许浏览器跨域（CORS）调用；若提示网络失败，请更换支持 CORS 的服务商或使用自定义反向代理地址。

## 项目结构

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架、顶部工具栏与 AI 设置弹窗 |
| `style.css` | 页面样式 + 三套模板样式 + AI 按钮/弹窗样式 + 打印样式 |
| `app.js` | 表单渲染、实时预览、照片压缩、模板切换、AI 美化（OpenAI 兼容接口调用）、数据保存 |
| `favicon.svg` | 浏览器标签页图标 |
| `screenshots/` | 效果截图 |
| `LICENSE` | MIT 开源协议 |

## 技术栈

原生 HTML + CSS + JavaScript，零依赖、零构建，浏览器直接运行；AI 美化基于 OpenAI 兼容的 `chat/completions` 接口，由用户自行配置服务商与密钥。

## 小技巧

- 在 URL 后加 `?demo=1` 可一键填充示例简历（真实案例：统计学背景转数据分析/数据运营方向），加 `&template=sidebar` 可直接预览侧边栏双栏模板，例如 `index.html?demo=1&template=sidebar`
